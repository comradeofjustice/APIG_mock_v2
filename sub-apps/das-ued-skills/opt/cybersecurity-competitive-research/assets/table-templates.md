# 表格模板速查

> 使用时直接复制对应模板，按格式填入内容。

---

## T1：设计作品表格（通用）

```markdown
| 作品 / 专辑 | 平台 | 链接 | 检索词 | 可借鉴点 |
|------------|------|------|--------|---------|
| **作品名**（作者，YYYY-MM） | 平台名 | [查看](URL) | 检索词 | 可借鉴点1；可借鉴点2；配色/布局特点 |
```

## T2：视频表格（通用）

```markdown
| 标题 | 链接 | 说明 |
|------|------|------|
| 视频标题（发布者，YYYY-MM） | [观看](URL) | 内容说明。参考价值说明。 |
```

## T3：竞品深度分析（宽表）

```markdown
| 字段 | 内容 |
|------|------|
| **名称** | 产品/报告全称 |
| **发布方** | 公司名 |
| **链接** | [查看官网](URL) · [附加链接说明](URL2) |
| **核心数据（YYYY）** | • 数据1：说明 • 数据2：说明 |
| **设计风格** | 深色/浅色；配色描述；布局形式；视觉语言特点 |
| **可借鉴点** | ① **要点名**：描述 ② **要点名**：描述 ③ **要点名**：描述 |
```

## T4：竞品集合一览（报告开头）

```markdown
| 类别 | 竞品 / 参考 | 形态 | 链接 |
|------|------------|------|------|
| **直接竞品（报告产品）** | 竞品名 | 形态 | [官网](URL) |
| **直接竞品** | 竞品名 | 形态 | [YouTube Demo](URL) |
| **间接竞品（平台级）** | 竞品名 | 形态 | [YouTube Demo](URL) |
| **设计概念参考** | 作品名（来源，年月） | 形态 | [Behance](URL) |
| **现状替代（用户当前在用）** | 替代方式 | 手工文档 | — |
```

## T5：分析框架（定位/优势/威胁/替代）

```markdown
| 维度 | 分析结论 |
|------|---------|
| **定位差异** | 各竞品面向谁、解决什么场景、主打差异化点 |
| **不对称优势** | 我方或某竞品难以复制的优势（数据/生态/品牌） |
| **真实威胁** | 竞争主要来自功能替代、渠道分发，还是商业模式 |
| **现状与替代** | 用户「不选任何一家」时在用什么（表格/手工/其他工具） |
```

## T6：图表类型参考表

```markdown
| 图表类型 | 适用场景 |
|---------|---------|
| **热力矩阵（Heatmap）** | 攻击频率分布、漏洞风险评分 |
| **桑基图（Sankey）** | 攻击路径流转、数据流向追踪 |
| **气泡图（Bubble）** | 漏洞数量 + 严重程度二维对比 |
| **折线/面积图** | 告警量时序趋势、MTTR/MTTD 变化 |
| **地理攻击地图** | 攻击源 IP 地理分布（大屏场景） |
| **进度环/仪表盘（Gauge）** | SLA 达成率、合规覆盖率 |
```

## T7：设计趋势分析表

```markdown
| 趋势 | 说明 |
|------|------|
| **深色（Dark）主导** | 说明深色主题使用比例和理由 |
| **品牌蓝 → 多色系** | 传统安全蓝向多维色彩体系演变 |
| **高亮点缀色** | 青色/电蓝/橙红作为强调色的使用规律 |
```
