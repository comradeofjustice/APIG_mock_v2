# parse-reference-image · 参考图解析

## 模式检测（全流程管线 vs 直接调用）

```
检测：docs/ux/{模块名}/session-state.md §参考图处理方式 是否存在？
  存在（全流程模式）→ 本 Skill 由 opt-prd-ux-code 或 b-admin-pencil-design 调用
                     不单独询问，直接执行解析，输出结果到对话上下文
  不存在（直接调用模式）→ 执行解析后，AskQuestion：
                          { id: "save",   label: "将解析结果保存为 docs/ux/{模块名}/image-spec.md" }
                          { id: "nosave", label: "仅在对话中展示，不保存文件" }
```

---

## 执行步骤

```
1. 读取传入的图片附件（截图 / 线框图 / 竞品参考图）
2. 用 AI Vision 分析图片，按以下四个维度提取结构化信息（每项用列表或表格输出）：
   a. 页面层级结构（IA）
   b. 主要组件列表
   c. 数据字段
   d. 操作入口
3. 输出「参考图解析结果」（格式见下方）
4. 按模式检测决定是否保存文件
```

---

## 输出格式

```markdown
## 参考图解析结果

### 页面层级结构（IA）
（Mermaid 图或多级列表，最多 3 层；描述页面/区域/模块的从属关系）

### 主要组件列表
| 组件类型 | 描述 | 位置 |
|---------|------|------|
| 表格 | 资产列表，含复选框、操作列 | 内容区主体 |
| 页头操作区 | 包含"新建"主按钮和搜索框 | 顶部 |
| 侧边筛选栏 | 按标签/状态筛选 | 左侧固定 |

### 数据字段
| 字段名 | 类型 | 说明 |
|--------|------|------|
| 名称 | 文本 | 资产/条目标题 |
| 状态 | 枚举 | 如"启用/停用" |
| 创建时间 | 日期时间 | — |

### 操作入口
| 操作名 | 位置 | 按钮类型 | 备注 |
|--------|------|---------|------|
| 新建 | 页头右侧 | 主按钮 | — |
| 编辑 | 行内操作区 | 文字链 | — |
| 删除 | 行内 / … 菜单 | 危险操作 | 需二次确认 |

### 设计说明（可选）
（若参考图有特殊布局、多 Tab、嵌套弹窗、非标交互模式，在此注明；无特殊情况则省略此节）
```

---

## 调用方使用说明

**被 opt-prd-ux-code 调用（Step B 参考图分支）：**
- 解析结果写入对话上下文，供 Stage 2 PRD 生成使用（「功能需求」和「页面清单」的结构来源）
- 同时写入 `session-state.md §参考图解析结果`

**被 b-admin-pencil-design 调用（步骤 0 设计系统还原模式）：**
- 解析结果作为步骤 1.5「页面清单确认」的输入依据
- 参考图内的颜色、圆角等视觉属性不传递到设计稿，由设计系统 Token 决定

**独立调用：**
- 适合用户想快速把截图转成功能清单、提炼 PRD 素材的场景
- 按模式检测决定是否存文件
